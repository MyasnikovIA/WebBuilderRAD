
## Как это использовать

### 1. В своих компонентах — указывайте `type: 'FILE'`

```js
{ name: 'icon', caption: 'Icon', type: 'FILE', attr: true },
{ name: 'src',  caption: 'Src',  type: 'FILE', attr: true },
{ name: 'href', caption: 'Href', type: 'FILE', attr: true }
```

Рядом с полем появится кнопка **«…»**. По нажатию открывается модальное окно с деревом файлов текущего проекта. Двойной клик по файлу в этом окне = сразу выбрать и закрыть. Или можно вписать путь вручную в поле ввода — кнопки и модалка не мешают ручному вводу.

### 2. Автодополнение для string-полей

```js
{ name: 'type', caption: 'Type', type: 'string', attr: true,
  suggest: ['primary', 'secondary', 'danger', 'ghost'] }
```

При вводе появится выпадающий список вариантов (нативный `<datalist>`). Свободный ввод остаётся возможным.

### 3. Многострочный `text`

Все поля с `type: 'text'` теперь:
- обычный `<textarea rows="3">` — можно писать сразу;
- **двойной клик** открывает полноэкранный `CodeEditor` с прокруткой и подсветкой `plaintext`.

### 4. `code`-поля

Все поля `type: 'code'` используют `CodeEditor` вместо голой `<textarea>`. Язык берётся из `f.language` (или `'javascript'` по умолчанию). Для существующего кода, где задан `code-editor` с динамическим языком — поведение сохранено.

---

## Что НЕ менялось

- `DomTree`, `Palette` — без изменений.
- Вся существующая логика `_editor` для `boolean`, `enum`, `color`, `length`, `number`, `image`, `images`, `code-editor` — сохранена.
- Все компоненты, кроме `cmpImage`, работают как раньше. Чтобы добавить им выбор файла — замените `type: 'string'` на `type: 'FILE'` в нужных полях.
